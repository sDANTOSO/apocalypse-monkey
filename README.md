# apocalypse-monkey
Apocolypse Monkey is an action visual novel, made in Godot.

## Features
This games features:
  - Custom Dialog
  - Custom Music
  - A custom visual novel system
  - Human drawn pixel art

## Story
Set in a post apocolyptic japan, were climate change has made the world into an ice age, billionares have a secret socciety who benefit of of this. But there is a hero.
